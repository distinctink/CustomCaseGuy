Before downloading, verify each image passes ALL of these checks:

- [ ] **No text/words/letters/numbers** anywhere in the image
- [ ] **No borders, margins, or white edges** — artwork bleeds to ALL 4 edges completely
- [ ] **Not a mockup** — should be flat 2D artwork, NOT shown on a phone/product
- [ ] **Correct colors** match the prompt description
- [ ] **Dense composition** — flowers/elements fill the entire canvas
- [ ] **Clean, modern illustration style** — NOT watercolor, NOT photorealistic, NOT vintage painting
- [ ] **9:16 portrait orientation** confirmed

If ANY check fails, **regenerate** that image. If text keeps appearing, add "absolutely no text, no words, no letters, no watermarks" to the end of the prompt.

Repeat this exact process for each of the 31 images:

1. **Clear** the previous prompt from the input field

7. **Select** the best option that passes all checks
8. **Download** the selected image (right-click > Save Image As, or use the download button)

10. **Move** the file to `Dropbox/JotForm/Distinct.Ink/florals-artwork/`
